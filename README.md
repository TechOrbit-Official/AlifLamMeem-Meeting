نظام تواصل تعليمي بين المعلمين والطلاب - نسخة الويب.

## 📁 هيكل المشروع

```
web-app/
├── index.html          # صفحة تسجيل الدخول
```

## 🚀 التشغيل السريع

### متطلبات
- متصفح حديث (Chrome, Edge, Firefox)
- السيرفر الخلفي شغال على `http://127.0.0.1:5000`

### التشغيل
```bash
# باستخدام Live Server (VS Code)
# أو
python -m http.server 5500

# أو فتح الملفات مباشرة في المتصفح
```

## 📋 المميزات

### صفحة تسجيل الدخول (`index.html`)
- تصميم عصري مع خلفية متحركة
- تسجيل دخول باسم المستخدم أو البريد الإلكتروني
- حفظ الجلسة في localStorage
- جلب رابط السيرفر تلقائياً من JSONBin

### صفحة المحادثة (`chat.html`)
- محادثة فورية عبر Socket.IO
- عرض جهات الاتصال حسب الصلاحيات:
  - **المدير**: يرى جميع المستخدمين
  - **المعلم**: يرى المشرفين + طلابه
  - **الطالب**: يرى معلمه فقط
- دعم الموبايل مع زر الرجوع
- اسم غرفة ثابت (ترتيب أبجدي)
- إرسال مزدوج (REST API + Socket.IO)

### لوحة التحكم (`dashboard.html`)
- إدارة كاملة للمستخدمين (إضافة/تعديل/حذف)
- إحصائيات: عدد المستخدمين، المعلمين، الطلاب
- بحث وتصفية حسب الدور
- ربط الطلاب بالمعلمين
- إدارة رابط السيرفر من JSONBin

## 🔗 روابط API المستخدمة

| الرابط | الوصف |
|--------|-------|
| `POST /api/login` | تسجيل الدخول |
| `GET /api/dashboard/json-data` | جميع المستخدمين |
| `GET /api/messages` | جلب الرسائل |
| `POST /api/messages` | إرسال رسالة |
| `GET /api/dashboard/stats` | إحصائيات |
| `POST /api/dashboard/users` | إضافة مستخدم |
| `PUT /api/dashboard/users/:id` | تعديل مستخدم |
| `DELETE /api/dashboard/users/:id` | حذف مستخدم |
